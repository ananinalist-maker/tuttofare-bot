# Tuttofare-Roma — бот квалификации заявок

Telegram-бот для семейной ремонтной мастерской в Риме и Витербо. Разговаривает с
клиентом на его языке (итальянский / русский / английский), за 7 вопросов собирает
данные по объекту, считает приоритет заявки и присылает мастеру карточку с готовым
решением: ехать на замер сегодня, завтра или не ехать вовсе.

## Какую задачу решает

У бизнеса бесплатная смета, но она готовится **только после реального выезда на объект**.
Значит каждый нецелевой лид — это потерянные полдня мастера, который в это время не
зарабатывает. Проблема усугубляется рынком: агрегаторы рекламируют «ремонт от 299 €/м²»,
а премиальный сегмент в Риме стартует от ~1 000 €/м². С холодного трафика это даёт
большой процент отказов уже на этапе сметы.

Бот закрывает разрыв: квалифицирует лид **до** выезда и честно отсекает тех, кому
не по адресу — по географии и по бюджету. Мастеру приходит не «здравствуйте, сколько
стоит ремонт», а карточка с приоритетом, площадью, сроком, бюджетом и подсказкой,
какое возражение будет у этого сегмента.

## Что умеет

- **Три языка без переключателя.** Язык определяется автоматически: сначала по тексту
  клиента (кириллица / итальянские / английские маркеры), затем по языку интерфейса
  Telegram. Переключить вручную можно в любой момент — `/lang`.
- **Скоринг лида 0–15 баллов** по пяти осям: география, тип работ, сегмент клиента,
  срок начала, бюджет. На выходе 🔥 горячий / 🌤 тёплый / ❄️ холодный / ⛔️ вне зоны.
- **Честный отказ вне географии.** Если объект не в Риме и не в Витербо, бот не тянет
  клиента через опрос ради контакта, по которому никто не поедет — говорит сразу.
- **Флаг «ценовой якорь».** Бюджет до 5 000 € на ванную или реновацию помечается
  отдельно: ожидания сформированы рекламой агрегаторов, вилку надо проговорить до выезда.
- **Подсказка по сегменту.** В карточке — главное возражение этого типа клиента и чем
  его крыть. Инвестору про DiCo и легальность, перфекционисту про A Corpo, архитектору
  про чтение чертежей.
- **Ничего не теряется.** Заявки пишутся в SQLite, команды `/leads` и `/stats` — для мастера.

## Стек

Python 3.12, [python-telegram-bot](https://python-telegram-bot.org) 21.x, SQLite.
Без внешних API и платных сервисов.

```
bot.py          сценарий диалога, команды, карточка мастеру
qualify.py      бизнес-логика: веса, скоринг, подсказки по сегментам
locales.py      тексты на трёх языках
lang_detect.py  определение языка клиента
storage.py      SQLite
config.py       переменные окружения
test_bot.py     локальные тесты (44 проверки, без обращения к сети)
```

## Запуск локально

```bash
git clone https://github.com/ananinalist-maker/tuttofare-bot.git
cd tuttofare-bot

python -m venv .venv
source .venv/Scripts/activate      # Windows (Git Bash)
# source .venv/bin/activate        # macOS / Linux

pip install -r requirements.txt
cp .env.example .env
```

Дальше:

1. В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен.
2. Вписать токен в `.env` в поле `BOT_TOKEN`.
3. Запустить `python bot.py`, написать боту `/id` — он ответит ваш chat id.
4. Вписать этот id в `.env` в поле `ADMIN_CHAT_ID` и перезапустить.

```bash
python bot.py
```

## Тесты

```bash
python test_bot.py
```

Токен не нужен: проверяется определение языка, скоринг, полнота переводов, база и
экранирование пользовательского ввода в карточке мастера.

## Деплой на Railway

Бот развёрнут и работает: проект `tuttofare-bot`, сервис `tuttofare-bot`,
том на 500 МБ в `/data`.

Через CLI (так он и разворачивался):

```bash
npm install -g @railway/cli
railway login
railway init --name tuttofare-bot
railway add --service tuttofare-bot
railway variables --set "ADMIN_CHAT_ID=<ваш id>" --set "DB_PATH=/data/leads.db"
cat .env | grep BOT_TOKEN | cut -d= -f2- | railway variables --set-from-stdin BOT_TOKEN
railway volume add --mount-path /data
railway up
```

Через веб-интерфейс: **New Project** → **Deploy from GitHub repo** → выбрать репозиторий →
**Variables** → вписать `BOT_TOKEN` и `ADMIN_CHAT_ID`. Start command Railway возьмёт
из `Procfile`.

### Грабли, на которые я наступил

- **Автодеплой по `git push` не работает без приложения Railway на GitHub.** Команда
  `railway add --repo` записывает репозиторий, но вебхук не создаётся. Либо ставить
  [Railway GitHub App](https://github.com/apps/railway-app), либо выкатывать вручную
  через `railway up`.
- **Два экземпляра на одном токене несовместимы.** Пока локальный бот опрашивает
  Telegram, серверный получает `Conflict: terminated by other getUpdates request`
  и наоборот. Перед деплоем локальный процесс надо погасить.
- **Git Bash на Windows подменяет пути в аргументах.** `--mount-path /data` превращается
  в `C:/Program Files/Git/data`. Лечится префиксом `MSYS_NO_PATHCONV=1`.
- **`railway volume add` падает с `--service`.** Внутренняя ошибка CLI
  (`panicked at volume.rs:836`). Работает без этого флага — том привязывается
  к текущему слинкованному сервису.

### Про базу

Файловая система контейнера эфемерная, поэтому база вынесена на том: `DB_PATH=/data/leads.db`.
Без тома `leads.db` обнулялся бы при каждом редеплое. Заявки при этом всё равно не терялись бы —
они приходят в Telegram, это основной канал доставки, база нужна для `/leads` и `/stats`.

### Про бесплатный тариф

Бессрочного бесплатного плана у Railway больше нет — при регистрации даётся пробный
кредит. Бот на long polling потребляет мало, но кредит конечен. Альтернативы для
круглосуточной работы: Fly.io, Hetzner CX22 (~4 €/мес), Contabo. На бесплатном тарифе
Render работать не будет — он усыпляет процесс, а long polling требует живого воркера.

### Известный долг

`railway.json` (Config as Code) объявлен устаревшим и поддерживается до 2026-12-01.
Миграция — `railway config migrate`, создаст `.railway/railway.ts`. Сейчас деплой
работает и через `Procfile`, так что это не срочно.

**Про бесплатный тариф.** У Railway пробный кредит, не бессрочный бесплатный план.
Бот на long polling потребляет мало, но кредит конечен. Альтернативы для круглосуточной
работы: Fly.io, Hetzner CX22 (~4 €/мес), Contabo. На Render бесплатный тариф не подойдёт —
он усыпляет процесс, а long polling требует постоянно живого воркера.

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `ADMIN_CHAT_ID` | да | Куда слать заявки. Несколько — через запятую |
| `DB_PATH` | нет | Путь к файлу базы, по умолчанию `leads.db` |
| `WHATSAPP_PHONE` | нет | Телефон в финальном сообщении клиенту |
| `SITE_URL` | нет | Ссылка на сайт |

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | Новая заявка |
| `/lang` | всем | Сменить язык |
| `/cancel` | всем | Отменить заполнение |
| `/help` | всем | Справка и контакты |
| `/id` | всем | Показать свой chat id (нужно при настройке) |
| `/leads` | мастеру | Последние 10 заявок |
| `/stats` | мастеру | Сводка по статусам |

## Как настроена квалификация

Веса живут в [`qualify.py`](qualify.py) и опираются на стратегию проекта, а не взяты с потолка:

- **География.** Север Рима (Parioli, Flaminio, Trieste, Cassia) и Витербо — максимум:
  там высокий чек и слабее онлайн-упаковка конкурентов. Другой регион — отказ.
- **Тип работ.** Сложные санузлы и крупноформатная плитка — ниша входа: укладка крупного
  формата с заусовкой 45° стоит 70–115 €/м² против 25–40 базовых, там видна и оплачивается
  квалификация мастера.
- **Сегмент.** Архитектор и дизайнер в приоритете: один партнёр приносит 5–7 проектов в год.
- **Бюджет.** Ориентиры рынка Лацио 2026: ванная под ключ 5 000–12 000 €, дизайнерская
  15 000–20 000 €, полная реновация 70–90 м² — 70 000–120 000 €.

Чтобы поменять пороги, достаточно отредактировать словари `GEO_SCORE`, `SERVICE_SCORE`,
`SEGMENT_SCORE`, `TIMING_SCORE`, `BUDGET_SCORE` — тесты сразу покажут, если что-то поехало.
